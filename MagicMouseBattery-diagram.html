🖱️ MagicMouseBattery

Aplicación macOS para monitorear batería de dispositivos Bluetooth

🎨 Capa Presentación
Menu Bar Icon
Icono en la barra de menú de macOS que muestra nivel de batería con indicador visual y texto en color
MenuBarView (SwiftUI)
Vista principal del popover con lista de dispositivos y configuración
DeviceBatteryView
Vista individual para cada dispositivo mostrando nombre, batería, ícono y botón de historial
BatteryHistoryView
Sheet con gráfico (Charts nativo) del nivel de batería en los últimos 7 días por dispositivo
↓
⚙️ Capa Servicios
BatteryService
Singleton que gestiona detección de dispositivos via IOKit, monitoreo continuo (60s visible, 300s oculto), actualización de estado e historial de batería (7 días, persistido en UserDefaults)
NotificationService
Envía notificaciones del sistema cuando batería baja del umbral configurado
LaunchAtLoginService
Gestiona la ejecución de la app al iniciar sesión
↓
📦 Capa Modelos
DeviceBattery
Estructura con id, name, batteryLevel, deviceType. Tipos: Magic Mouse, Magic Keyboard, Magic Trackpad
BatteryReading
Estructura Codable con date, level. Una lectura puntual de batería usada en el historial por dispositivo
↓
🔧 Integraciones del Sistema
IOKit
Framework de macOS para acceder a dispositivos USB/Bluetooth. Detecta AppleDeviceManagementHIDEventService
UserNotifications
Framework para enviar notificaciones del sistema
AppKit
Manejo del popover, status item y ciclo de vida de la app
📊 Flujo de Datos Principales
App Launch → AppDelegate.applicationDidFinishLaunching()
setupStatusItem() → Menu Bar Icon visible
BatteryService.startMonitoring() → Timer cada 60s/300s
Refresh() → IOKit detecta dispositivos Bluetooth
@Published devices actualiza MenuBarView y DeviceBatteryView
recordHistory() añade una BatteryReading por dispositivo (retención 7 días, UserDefaults)
onDevicesUpdated callback → updateStatusItemImage() + checkBatteryLevels()
Si batería < umbral → NotificationService envía notificación
Menu icon color y porcentaje se actualizan dinámicamente
🏗️ Patrón Arquitectónico
MVVM + Singleton Pattern + Observer Pattern (Combine)
⚡ Tecnologías
SwiftUI, AppKit, IOKit, Combine, UserNotifications, Charts
📱 Plataforma
